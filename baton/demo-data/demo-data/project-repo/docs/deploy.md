# Deploying the Orbit site

1. Merge to main. The host rebuilds automatically.
2. Check the /health page after each deploy.
3. If the build fails, roll back to the previous release from the host dashboard.

## Domain

The club domain is registered through the college-approved registrar.
It renews every year on 30 June.

## Registration form

The registration form lives in the club workspace and is owned by the treasurer account.
Responses land in a shared sheet.

## Hosting

The site runs on a free-tier plan. A move to a new hosting plan is tracked in issue 18.
